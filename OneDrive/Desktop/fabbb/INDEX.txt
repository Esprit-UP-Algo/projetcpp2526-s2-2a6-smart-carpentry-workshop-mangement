ARCHITECTURE VISUELLE
═══════════════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────────────┐
│                          MainWindow                                    │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  ┌─ DONNEES ─────────────────┐                                        │
│  │ QList<EtapeData>          │  → Structure avec:                     │
│  │ m_etapesList              │    - id, nom, ordre, dates            │
│  │                           │    - tempsEstime, tempsReel           │
│  │                           │    - etat (calculé en SQL)            │
│  └───────────────────────────┘                                        │
│          ↓ chargerEtapes()                                            │
│  ┌─ DB QUERY ─────────────────┐                                       │
│  │ QSqlQuery avec CASE        │  → SELECT IDETAPE, NOMETAPE, ...    │
│  │ Calcul dynamique ETAT_ETAPE│    CASE WHEN ... THEN ...           │
│  └───────────────────────────┘    FROM ETAPE WHERE IDFAB = ?        │
│          ↓                                                             │
│  ┌─ TABLEAU ──────────────────┐                                      │
│  │ QTableWidget               │  → 9 colonnes: ID, Nom, Ordre, ..., │
│  │ m_tableEtapes              │    Statut (color-coded)              │
│  │ 9 colonnes                 │                                      │
│  │ Color-coded rows           │                                      │
│  └───────────────────────────┘                                       │
│          ↓                                                             │
│  ┌─ TIMELINE VISUELLE ────────┐                                      │
│  │ QScrollArea                │  → Cartes horizontales:              │
│  │ Cartes d'étapes            │    Étape 1 → Étape 2 → Étape 3     │
│  │ Colores par statut         │    Chaque carte avec badge coloré   │
│  │ Flèches de séparation      │                                     │
│  └───────────────────────────┘                                       │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

FLUX DE DONNÉES:
  
  chargerEtapes(int idFab)
       ↓
  Prépare QSqlQuery avec CASE
       ↓
  Exécute: SELECT ... CASE WHEN ... THEN ETAT_ETAPE FROM ETAPE WHERE ...
       ↓
  Stocke résultats dans m_etapesList
       ↓
  Remplit m_tableEtapes avec les données
       ↓
  Appelle afficherTimelineEtapes()
       ↓
  Crée des cartes visuelles avec couleurs
       ↓
  Affiche timeline horizontale

RÈGLES MÉTIER - STATUTS D'ÉTAPES
═══════════════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────────────┐
│                  ÉTATS POSSIBLES DE L'ÉTAPE (ETAPE)                     │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  1️⃣  NON_PLANIFIEE (🔴 ROUGE #DC3545)                                 │
│      Condition: DATEDEBUT IS NULL                                     │
│      Signification: Pas encore d'ordre de démarrage                   │
│      Exemple: Étape prévue pour le mois prochain                      │
│                                                                       │
│  2️⃣  PLANIFIEE (🟠 ORANGE #FFC107)                                   │
│      Condition: DATEDEBUT NOT NULL AND TEMPSREEL = 0 AND DATEFIN NULL│
│      Signification: Assignée à une date, pas commencée               │
│      Exemple: Préparation du travail                                  │
│                                                                       │
│  3️⃣  EN_COURS (🟡 JAUNE #FFEB3B)                                    │
│      Condition: DATEDEBUT NOT NULL AND TEMPSREEL > 0 AND DATEFIN NULL │
│      Signification: Actuellement en exécution                        │
│      Exemple: Suivi du temps réel en cours                           │
│                                                                       │
│  4️⃣  TERMINEE (🟢 VERT #28A745)                                     │
│      Condition: DATEFIN NOT NULL AND TEMPSREEL <= TEMPSESTIME       │
│      Signification: Complétée dans les délais                        │
│      Exemple: Travail terminé, pas de dépassement                    │
│                                                                       │
│  5️⃣  EN_RETARD (🔴 ROUGE FONCÉ #8B0000)                             │
│      Condition: DATEFIN NOT NULL AND TEMPSREEL > TEMPSESTIME        │
│      Signification: Terminée mais avec dépassement horaire           │
│      Exemple: Travail fini, mais 2h de plus que prévu               │
│                                                                       │
└─────────────────────────────────────────────────────────────────────────┘

TRANSITION D'ÉTATS (WORKFLOW):

  NON_PLANIFIEE
        ↓ (DATEDEBUT renseignée)
  PLANIFIEE
        ↓ (TEMPSREEL > 0)
  EN_COURS
        ↓ (DATEFIN renseignée)
  ├─→ TERMINEE (si TEMPSREEL ≤ TEMPSESTIME)
  └─→ EN_RETARD (si TEMPSREEL > TEMPSESTIME)

SUPPORT & TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Erreur: Compilation échoue
─────────────────────────
  → Vérifier tous les includes
  → Vérifier structure EtapeData dans mainwindow.h
  → Copier les fonctions complètes depuis etapes_implementation.cpp

Erreur: Tableau vide
──────────────────
  → Vérifier IDFABRICATION existe en DB
  → Exécuter la requête SQL directement en SQL Developer
  → Consulter TESTING_GUIDE.cpp → testTableEtape()

Erreur: Couleurs ne s'appliquent pas
────────────────────────────────────
  → Vérifier couleurEtatEtape() retourne bonne couleur
  → Vérifier item->setBackground() après setItem()
  → Exécuter testCouleurs() pour debug

Erreur: Timeline ne s'affiche pas
─────────────────────────────────
  → Vérifier m_timelineContainer est initialisé
  → Vérifier afficherTimelineEtapes() est appelé
  → Vérifier m_etapesList n'est pas vide
